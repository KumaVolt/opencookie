Everything a cookie banner should do, nothing it shouldn't

A banner shows a choice, holds back scripts until that choice is made and keeps a record of it. Hosted services charge for that per domain, every month. OpenCookie does it on a server you already have.

  • Finds the cookies for you

    A headless browser visits up to 20 pages of each site, first without consent and then after accepting, and looks every cookie up in the Open Cookie Database.

  • Rules per country

    Rule packs for the Dutch AP, the EDPB, CNIL, German TDDDG, UK DUAA and US GPC decide what the banner must do and what the compliance check looks for.

  • Blocks before it asks

    Scripts and embeds from about 50 known services wait until the visitor agrees. Google Consent Mode v2 is sent with every choice.

  • A fair banner

    Reject sits next to Accept and looks the same. Nothing is pre-ticked, there is no cookie wall, and it works with a keyboard and a screen reader.

  • Proof of consent

    Each choice is logged with its policy version and a hashed, truncated IP address, in a SQLite file on your server. Export it as CSV when someone asks.

  • Built for agencies

    Each client gets its own sites, team and statistics. Owners, editors and viewers; passkeys and 2FA for everyone.

Run your own

You need a server with Docker and a domain for OpenCookie, such as consent.yoursite.com.

With Docker

docker run -d --name opencookie --restart unless-stopped \
  -p 8080:8080 -v opencookie-data:/data \
  -e PUBLIC_URL=https://consent.yoursite.com \
  -e TZ=Europe/Amsterdam \
  ghcr.io/kumavolt/opencookie

Point your HTTPS proxy at port 8080, run docker logs opencookie for the setup key, then open /admin/ on your domain. Runs on amd64 and arm64.

With your AI assistant

Install OpenCookie on this server with Docker, using the image ghcr.io/kumavolt/opencookie (docs: github.com/KumaVolt/opencookie). Serve it on https://consent.yoursite.com with HTTPS, set PUBLIC_URL and TZ, keep /data on a volume, and tell me the setup key from the container log.

Paste it into Claude Code, Codex or another coding assistant on your server. Change the domain to yours.

Then add one line to your site

Add a site in the admin. It shows a line like this; put it first in the <head> of every page.

<script src="https://consent.yoursite.com/s/SITE_KEY/banner.js"></script>

Your AI assistant can also manage your sites afterwards: OpenCookie has an MCP server. Create an access token under Your account to connect it.
